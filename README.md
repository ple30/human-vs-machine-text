# Group 52: COMP90051 Statistical Machine Learning Project Project 2
- In this project, we build a human versus machine-generated text classifier. We evaluate three approaches: Naive-Bayes, Logistic Regression, and a Multitask CNN model on a test dataset. It shows that a Multitask CNN performs best. The final model as described in the report is in the final_model.ipynb. The notebook uses standard libraries except 'optuna', which we have already included the code to install it in the notebook.
